# Modern Reliverse open-sourcing

This commit begins the progressive open-sourcing of the modern Reliverse codebase after the June 8, 2026 public checkpoint.

Reliverse remains developed in public through bounded GR campaigns. Modern subsystems will land incrementally so each public transition can preserve explicit scope, reviewable provenance, and a normal non-force Git history.

This bootstrap commit intentionally does not publish packages, deploy production infrastructure, or claim that every VPS-only subsystem is already public. Those transitions follow in later governed campaigns.
